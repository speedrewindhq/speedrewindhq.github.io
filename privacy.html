Privacy Policy

SpeedRewind Clipper · last updated 15 October 2026

SpeedRewind Clipper is a private tool used by one person to publish video clips to their own social accounts. It has no other users, no sign-up, and no way for anybody else to connect an account to it.

What it accesses

When the operator authorises the app against their own accounts, it is granted permission to:

  • YouTube — upload videos to the operator's own channel, set thumbnails and scheduled publish times, and read that channel's own video statistics (views, durations) to judge how clips performed.
  • Instagram — publish Reels to the operator's own professional account and read that account's basic profile information.

It never reads another person's account, and it never acts on behalf of anyone but the operator.

What it stores, and where

Authorisation tokens are written to a file on the operator's own computer and are never transmitted anywhere except back to Google and Meta to make the requests above. There is no server, no database and no hosted component: the tool runs entirely on one machine.

Alongside those tokens the tool keeps a local record of what it published — video IDs, titles, timestamps and view counts for the operator's own posts. That record also stays on that machine.

What it does not do

  • No data is sold, shared, or given to any third party.
  • No advertising, analytics or tracking of any kind.
  • No personal information is collected from viewers, subscribers or commenters.
  • Nothing is collected from visitors to this website. It is static pages with no cookies, no scripts and no logging beyond what GitHub Pages does to serve the files.

Google user data

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements. Google data is used only to upload and manage the operator's own videos and to read that channel's own statistics. It is not used to train any model, is not transferred to others, and is not used for advertising.

Retention and revoking access

Tokens are kept only while the tool is in use, and deleting the local token file ends the app's access immediately. Access can also be withdrawn at any time from the account side:

  • Google — myaccount.google.com/permissions
  • Instagram — Settings → Apps and websites

Revoking from either place takes effect at once and the tool stops being able to post.

Changes

If what the tool does changes, this page changes with it, and the date at the top is updated.
